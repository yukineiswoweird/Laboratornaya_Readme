# Управление пользователями и ролями

Учебный проект на C#, состоящий из ASP.NET Core Web API, WPF-клиента и базы данных SQLite. Приложение позволяет просматривать и добавлять пользователей и роли, а также пересоздавать базу данных.

## Состав проекта

- **WebApplication1** — серверное приложение ASP.NET Core Minimal API.
- **WpfApp1** — настольный клиент на WPF, который отправляет HTTP-запросы к серверу.
- **SQLite** — хранение пользователей и ролей в файле `helloapp.db`.
- **Entity Framework Core** — работа с базой данных.

## Возможности

- Получение списка пользователей вместе с названиями их ролей.
- Добавление пользователя с логином, паролем и ID роли.
- Получение списка ролей.
- Добавление новой роли.
- Пересоздание базы данных и заполнение её начальными данными.

При первом создании базы добавляются две роли — `admin` и `user`, а также два тестовых пользователя:
- `Tom` — роль с ID `1`;
- `Alice` — роль с ID `2`.

> Внимание: в текущей реализации конструктор `ApplicationContext` вызывает `EnsureDeleted()` и `EnsureCreated()`. Поэтому база данных удаляется и создаётся заново при создании контекста. Не используйте проект с важными данными без изменения этой логики. Тестовые пароли хранятся в открытом виде; для реального приложения необходимы безопасное хеширование паролей и дополнительная защита API.

## Запуск

### 1. Запустить API-сервер

Откройте терминал в каталоге `WebApplication1/WebApplication1` и выполните:

```bash
dotnet restore
dotnet run
```

В конфигурации проекта HTTP-адрес сервера по умолчанию:

```text
http://localhost:5249/
```

Оставьте сервер запущенным. База `helloapp.db` создаётся в рабочем каталоге приложения.

### 2. Запустить WPF-клиент

Откройте `WpfApp1/WpfApp1/WpfApp1.csproj` в Visual Studio и запустите проект. В поле «Ссылка» по умолчанию указан адрес `http://localhost:5249/`.

Нажмите **«Вставить ссылку»**, чтобы сохранить адрес сервера в клиенте, затем используйте кнопки для получения и добавления пользователей и ролей.

## HTTP API

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/get` | Получить пользователей вместе с данными роли |
| `POST` | `/post` | Добавить пользователя |
| `GET` | `/getRole` | Получить список ролей |
| `POST` | `/postRole` | Добавить роль |
| `POST` | `/recreate` | Пересоздать базу и добавить начальные данные |

### Примеры запросов

Добавление пользователя (`POST /post`):

```json
{
  "login": "Alex",
  "password": "example-password",
  "roleId": 2
}
```

Добавление роли (`POST /postRole`):

```json
{
  "name": "manager"
}
```

Для запросов с JSON указывайте заголовок `Content-Type: application/json`.

## Как пользоваться клиентом

1. Запустите сервер.
2. Убедитесь, что в поле адреса указан правильный URL API.
3. Нажмите «Вставить ссылку».
4. Нажмите «Получить пользователей» или «Получить роли», чтобы загрузить данные.
5. Для добавления пользователя заполните логин, пароль и ID существующей роли, затем нажмите «Добавить пользователя».
6. Для добавления роли укажите её название и нажмите «Добавить роль».
7. Кнопка «Пересоздать БД» удаляет и создаёт базу заново, после чего добавляет начальные записи. **Все существующие данные будут потеряны.**

## Примечания

- Указывайте ID роли, которая существует в базе данных.
- Если клиент не подключается, проверьте, что API запущен и адрес совпадает с адресом сервера.
- Обработка сетевых ошибок в клиенте ограничена; при ошибке проверьте вывод сервера и терминала.
